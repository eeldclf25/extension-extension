# Extension Extension

The extension that makes extensions better.

## Features

This extension provides navigation utilities for extensions.

- **Extension Navigation View**: A dedicated view in the activity bar for navigation.
- **Daily Calendar**: Quickly open your full daily calendar.
- **Integration**: Supports links to Foam daily notes.

## Extension Settings

This extension contributes the following settings:

* `extext.dailyNotesDirectory`: The path to the folder containing daily notes.
